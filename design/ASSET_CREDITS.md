# Asset provenance

- Campfire, crafting bench, backpack and environment reference: the user's Drawcall Design project **VR Survival Crafting — Visual Moodboard** (`e6g1v97kawuuwu`). Original GLTS snapshots and design documents are preserved in `source/`; runtime adaptations live in `src/scene-assets/`.
- `public/models/pine-1.glb` and `pine-2.glb`: Quaternius **Stylized Nature MegaKit Standard**, Pine 1 and Pine 2, CC0 1.0 Universal. [Original pack](https://quaternius.com/packs/stylizednaturemegakit.html), [itch.io page](https://quaternius.itch.io/stylized-nature-megakit). The source asset README files are preserved in `source/`. Runtime copies adjust material tint/roughness and preserve compressed geometry.
- Wood/bark texture patterns and the additional supply stand, striking pad and gameplay pieces are procedural local adaptations. Runtime assets use the shared IWSDK manifest.
